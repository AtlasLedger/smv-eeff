# Licencia de los datos

La base de datos contenida en `data/` (y sus copias en otros repositorios) se pone a
disposición bajo la **Open Data Commons Open Database License (ODbL) v1.0**:
https://opendatacommons.org/licenses/odbl/1-0/

Los contenidos individuales de la base se ponen a disposición bajo la Database Contents
License: https://opendatacommons.org/licenses/dbcl/1-0/

## Atribución

Base derivada de los datos abiertos de la **Superintendencia del Mercado de Valores del
Perú (SMV)**, publicados bajo la licencia ODbL v1.0. La SMV no participa en este proyecto
ni respalda sus transformaciones.

Si usas o redistribuyes esta base, la ODbL exige:

1. **Atribuir**: mencionar a la SMV como fuente original y a este proyecto como base derivada.
2. **Compartir igual**: si publicas una base derivada de esta, debe ir bajo ODbL.
3. **Mantener abierto**: si la distribuyes con restricciones técnicas, ofrecer también
   una versión sin ellas.

El código del proyecto (carpetas `smv/`, `scripts/`, `tests/`) tiene licencia MIT (ver `LICENSE`).
